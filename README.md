# JLPT 헌터 · N2 학습

JLPT N2 **어휘·한자·문법** 학습 웹앱. 간격 반복으로 매일 외우고, 자투리 시간에 바로 쓸 수 있게 만들었습니다.
서버 없이 동작하는 정적 사이트이며 학습 기록은 브라우저 localStorage에 저장됩니다.

정처기 학습앱(`../jeongcheogi`)에서 실제로 효과가 확인된 구조를 재사용했습니다.

## 담긴 것

| 구분 | 개수 | 내용 |
|---|---|---|
| 어휘 | 218 | 명사 119 · 동사 40 · 형용사 38 · 부사 16 · 접속사 5 |
| 한자 | 30 | 음독·훈독 구분 + 예시 단어 96개 |
| 문법 | 30 | N2 문형 + **비슷한 문형 비교 60개** |
| **합계** | **278** | 연어 357개 포함 |

## 왜 어휘·문법만 다루는가

JLPT N2는 **총점 90/180점 이상 + 각 영역(언어지식·독해·청해) 19점 이상**이 합격 조건입니다.
한 영역이라도 과락이면 총점이 높아도 불합격이므로 **버리는 전략이 불가능**합니다.

그런데 영역마다 학습 매체 적합도가 다릅니다.

| 영역 | 앱 적합도 | 이유 |
|---|---|---|
| **문자·어휘** | 매우 높음 | 단답형. 간격 반복이 가장 잘 먹힘 |
| **문법** | 높음 | 문형 구분 + 선택지형 |
| 독해 | 낮음 | 긴 지문은 폰 화면에서 읽기 불편, 자투리 시간 부적합 |
| 청해 | 앱만 가능하나 음성 필요 | 음원 제작 불가 |

그래서 역할을 나눴습니다.

```
이 앱       →  문자·어휘 + 문법
교재/문제집  →  독해 (긴 지문은 종이가 빠름)
음원 자료    →  청해 (유튜브·교재 음원)
```

어휘·문법은 독해·청해의 기초이기도 해서, 여기 투자하면 세 영역 모두에 효과가 번집니다.

## 기능

- **오늘 학습** — 앱을 열면 지금 봐야 할 것을 자동으로 띄웁니다. 필터 선택 없이 바로 시작
  - 우선순위: 복습 기한 → 새 단어 → 새 한자 → 새 문법
  - 왜 이 항목을 보는지도 함께 설명
  - 하루 목표 20개, 연속 학습일 추적
- **간격 반복** — 외우면 1→2→3→4→5→6단계로 올라가며 간격이 1·2·4·8·15·30일로 벌어집니다. 틀리면 1단계로 떨어져 내일 다시 나옵니다
- **인출 연습** — 답을 떠올려 적어보는 입력란(선택). 읽기만 하면 아는 것 같지만 백지에서는 안 나옵니다
  - **로마자 입력** — 일본어 입력기 없이 `eikyou` 를 치면 `えいきょう` 가 됩니다.
    대문자는 가타카나(`NICHI` → `ニチ`), 한글·기호는 그대로 통과하므로
    `eikyou 영향` 처럼 섞어 쓸 수 있습니다. 입력란 아래 체크박스로 끌 수 있습니다.
    실제 입력기처럼 끝에 홀로 남은 `n` 은 Enter·포커스 이탈 때 확정됩니다(`hon` → `ほん`)
- **학습 우선 정렬** — 탭을 열면 **지금 공부할 것부터** 나옵니다. 이미 외운 항목은 맨 뒤로 밀립니다
  - 순서: 복습 기한(약한 단계 먼저) → 모르겠음 → 애매함 → 아직 안 본 것 → 외운 것
  - 필터 패널에서 '등록 순서'로 바꿀 수 있습니다 (사전처럼 훑어볼 때)
- **단어** — 읽기·뜻·예문(일본어/읽기/해석 3층)·연어·학습 포인트
- **한자** — 음독(カタカナ)과 훈독(ひらがな)을 나눠 표시 + 예시 단어
- **문법** — 문형·접속 형태·예문 + **비슷한 문형과의 구분** (N2의 핵심)
- **약점** — "애매함"·"모르겠음"으로 표시한 항목만 모아보기
- **진도** — 종류별 진도, 복습 단계 분포, 최근 학습 기록
- 다크모드 자동 대응, 모바일 반응형, 오프라인 동작(PWA)

## 데이터 출처와 검증 (중요)

읽기는 **사람이 적지 않습니다.** 모든 읽기가 사전(JMdict) 조회를 거칩니다.

| 항목 | 개수 | 검증 결과 |
|---|---|---|
| 어휘 표제어 | 218 | **전부 사전 일치** |
| 어휘 예문 읽기 | 218 | **전부 사전 근거 확인** |
| 연어 읽기 | 357 | **전부 사전 근거 확인** |
| 한자 예시 단어 | 96 | **전부 사전 일치** |
| 문법 예문 읽기 | 30 | **전부 사전 근거 확인** |
| **합계** | **919** | **919 확인 / 설명 불가 0** |

```bash
node tools/verify-readings.mjs    # 919개 전수 검증
node tools/check.mjs              # 형식 검사 (ID·필드·안내문 누출)
```

### 어떻게 검증하는가

문장을 `한자덩어리 + 오쿠리가나` 조각으로 자르고, 조각마다 **가능한 읽기 후보**를
사전에서 모은 뒤, 저장된 읽기를 그 후보들의 조합으로 끝까지 설명할 수 있는지 봅니다.

```
外では激しい雨が降っている。
  ↓ 조각
[外では] [激しい] [雨が] [降っている]
  ↓ 후보 (사전)
そとでは|がいでは  はげしい  あめが  ふっている
  ↓
저장된 "そとでははげしいあめがふっている。" 를 설명 가능 → 통과
```

읽기 근거는 세 경로뿐입니다.

1. **사전 표제어** — 조각 전체가 등재되어 있으면 그 읽기
2. **사전형의 어간** — 활용형은 `tools/stems.json` 에 사전형을 명시하고,
   사전 읽기에서 꼬리를 떼어 어간을 얻습니다 (198개 등재)
3. **활용 규칙** — 불규칙 동사만 해당. 현재 `来ない`(こない) 1건이며
   보고서에 '사전 미확인'으로 따로 집계됩니다

### 이 검증으로 잡은 실제 오류 (11건)

```
誤りを認める      ごり…        →  あやまり…      誤り는 ご가 아니다
手段を選ばない     …せんばない    →  …えらばない    選 의 명사 읽기를 잘못 집음
貿易が盛んだ      …もりんだ     →  …さかんだ
助けを求める      じょけを…     →  たすけを…
気持ちが落ち着く    きもちちが…    →  きもちが…      ち 중복
落ち着いた色      おちちゃくいた… →  おちついた…
豊かな生活       ゆたかかな…    →  ゆたかな…      か 중복
経験が豊かだ      …ゆたかかだ    →  …ゆたかだ
明らかに        みょうらかに   →  あきらかに
研究が盛んだ      …もりんだ     →  …さかんだ
外では激しい雨…    そとではげしい… →  そとでははげしい…  は 누락
```

### 여전히 남는 한계
- **한국어 뜻, 예문의 자연스러움, 뉘앙스 설명은 사전으로 검증되지 않습니다.**
  읽기가 맞다는 것이 문장이 자연스럽다는 뜻은 아닙니다. 교재와 교차 확인하세요.
- "기출 N회 출제" 같은 빈도 표시가 없습니다. 만들 근거가 없기 때문입니다.
- 독해·청해는 반드시 별도 교재가 필요합니다.


### 어휘 (`data/vocab.js`)

```js
{
  id: "v-121",
  w: "影響",                    // 단어 (한자 표기)
  r: "えいきょう",               // 읽기 — 한자가 섞이면 검사기가 잡아냅니다
  m: "영향",
  pos: "명사",                  // 명사/동사/형용사/부사/접속사
  level: "N2",
  ex: "天気が農業に影響を与える。",
  exr: "てんきがのうぎょうにえいきょうをあたえる。",
  exm: "날씨가 농업에 영향을 준다.",
  collo: [                      // 선택 — 연어. 읽기(r)는 필수
    { c: "影響を与える", r: "えいきょうをあたえる", m: "영향을 주다" }
  ],
  tip: "「〜に影響を与える」 형태로 통째로 외우는 것이 실전에 유용하다."
}
```

### 한자 (`data/kanji.js`)

```js
{
  id: "k-031",
  kanji: "生",                  // 반드시 한자 한 글자
  level: "N2",                  // N2 또는 N3
  meaning: "날 생, 살다",
  on: ["セイ", "ショウ"],        // 음독 — 카타카나
  kun: ["い(きる)", "なま"],      // 훈독 — 히라가나
  words: [
    { w: "生活", r: "せいかつ", m: "생활" }
  ],
  tip: "읽기가 가장 많은 한자다. 一生(いっしょう)처럼 ショウ로 읽는 경우를 따로 기억해야 한다."
}
```

### 문법 (`data/grammar.js`)

```js
{
  id: "g-031",
  pattern: "〜おかげで",
  group: "원인·이유",            // 분류 (필터에 자동 반영)
  level: "N2",
  form: "명사の / 동사た형 + おかげで",
  mean: "~덕분에 (좋은 결과)",
  ex: "先生のおかげで合格できました。",
  exr: "せんせいのおかげでごうかくできました。",
  exm: "선생님 덕분에 합격할 수 있었습니다.",
  note: "반드시 좋은 결과에만 쓴다.",
  confuse: [                    // N2는 문형 구분이 핵심이므로 가능하면 채우세요
    { p: "〜せいで", d: "~탓에 (나쁜 결과)" }
  ]
}
```

### 반드시 지킬 것: ID는 바꾸지 않기

학습 기록은 **항목 ID를 키로** 저장됩니다 (`v:v-001`, `k:k-001`, `g:g-001`).

- **새 항목 추가** → 안전. 기존 기록 유지
- **기존 항목의 ID 변경** → 그 항목의 기록이 사라집니다

데이터를 크게 갱신했으면 `sw.js`의 `CACHE` 값을 올리세요 (`nihongo-v1` → `nihongo-v2`).
